# Portofolio Fachri Adrian Syahputra

Website portofolio akademik sederhana yang dibuat dengan HTML dan CSS.

## Publikasi dengan GitHub Pages
1. Buka tab **Settings** pada repository.
2. Pilih **Pages** pada menu samping.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch **main** dan folder **/(root)**, lalu klik **Save**.
5. Tunggu proses deployment selesai.

Alamat situs: https://fahriadriansyahputra.github.io/
